# Documentation map

Start with `../README.md`, `PAPER_PROTOCOL.md` and `PAPER_ARTIFACTS.md` for the supplied gateway co-observation paper and corrected protocol v3.

`PAPER_SUPPLIED.md` is the exact supplied manuscript. `../MANUSCRIPT_FINAL.md` is a separate pre-existing manuscript version. Neither has been silently rewritten following implementation fixes.

The remaining documentation describes earlier development phases: `BLE_MODEL.md`, `GROUND_TRUTH.md`, `EDGE_PROCESSING.md`, `DATA_MODEL_v2.md`, `RISK_MODEL.md`, `EVALUATION_PROTOCOL.md`, `REPRODUCIBILITY.md`, `FINAL_EXPERIMENTAL_PROTOCOL.md` and the privacy documents. They remain useful for module background or older experiments but do not override v3 labels, aggregation, fixed Bayesian-table provenance or timing disclosures. Privacy experiments are outside the supplied paper's scope. Historical result packages and audit prose are recoverable from the external archive recorded in `../CLEANUP_REPORT.md`.
