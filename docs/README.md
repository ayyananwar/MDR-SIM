# Documentation map

Start with `../README.md`, `ML_V7_PROTOCOL.md` and `PROJECT_BEGINNER_GUIDE.md` for the current trained contact-reconstruction study. `PAPER_PROTOCOL.md` and `PAPER_ARTIFACTS.md` describe the earlier corrected gateway campaign (v3).

`PAPER_SUPPLIED.md` is the exact supplied manuscript. `../MANUSCRIPT_FINAL.md` is a separate pre-existing manuscript version. Neither has been silently rewritten following implementation fixes.

The remaining documentation describes earlier development phases: `BLE_MODEL.md`, `GROUND_TRUTH.md`, `EDGE_PROCESSING.md`, `DATA_MODEL_v2.md`, `RISK_MODEL.md`, `EVALUATION_PROTOCOL.md`, `REPRODUCIBILITY.md`, `FINAL_EXPERIMENTAL_PROTOCOL.md` and the privacy documents. They remain useful for module background or older experiments but do not override v3 labels, aggregation, fixed Bayesian-table provenance or timing disclosures. Privacy experiments are outside the supplied paper's scope. Historical evidence is retained in versioned result folders and the research release; see `../REPRODUCIBILITY_RELEASE.md`.
